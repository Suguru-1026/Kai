# KNA-1.1 Kanami — Chat Specialist v1.2

## 今回の追加

- 制限付き自己学習ループ：内蔵プロンプトへ複数回答を生成し、採用した回答と元の教師データの一部を混ぜて学習し、更新後のモデルで次周回を実行します。
- 既定は1周・4プロンプト・各1回答。UI上限は3周、8プロンプト、各2回答。ハード上限は48生成・24 optimizer更新です。
- 回答は空文字・長すぎる出力・UTF-8不正・極端なToken反復を除外します。自己生成回答は正解ではないため、元データをアンカーとして混ぜ、検証Lossもループ後に再測定します。
- 構成プリセットを最小／中間／通常に拡張。最小=hidden 16/1層/2ヘッド/context 192、中間=24/2層/2ヘッド/context 224、通常=32/2層/4ヘッド/context 256。

## 起動

1. ZIPを展開し、`index.html` とJSファイルを同じフォルダーに置きます。
2. `index.html` を開きます。外部ライブラリ・ネット接続は不要です。
3. まず最小構成で通常の教師データ学習を実行し、必要に応じて「生成→学習ループ開始」を1周から試します。
4. 構成を大きくするとモデル重みとOptimizer状態は初期化されます。現在の実装では、小さい構成から大きい構成への重み移植は未実装です。したがって、段階的な構成選択はできますが、学習済み重みを保持したままの拡張ではありません。

## 安全な運用上の注意

自己学習はモデル自身の出力を疑似ラベルとして再学習します。出力の品質を保証せず、誤答・反復・無意味な出力を強化する可能性があります。最大3周・48生成・24更新に制限し、元の学習例を混ぜますが、劣化を完全に防ぐ仕組みではありません。生成例はログに出力されるので確認し、検証Lossが悪化した場合は保存・採用しないでください。評価データは学習ループのOptimizer更新には使用しません。

## 構成

- 14 JavaScriptファイル（自己学習制御 `self-training.js` を追加）
- `index.html`
- 日本語対話データとtrain/validation split
- `SPEC-1.0-GAP-REPORT.md`, `AUDIT-FIXES.md`, `VERIFICATION-RESULTS.json`

このモデルはCPU/FP32の小規模な研究・学習用プロトタイプです。事前学習済みモデルではなく、実用的な汎用チャット能力を保証しません。ブラウザー実機での全面検証は未完了です。
